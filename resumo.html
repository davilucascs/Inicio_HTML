Quais sao os comando do Git que aprendemos ?

Os principais comandos do git sao: git init faz ? : O comando git init é utilizado para transformar um diretório local comum em um novo repositório Git vazio

- git clone [url] faz ? : O comando git clone [url] é utilizado para criar uma cópia local completa de um repositório Git remoto

- git add [arquivo] faz ? : O comando git add [arquivo] é utilizado para mover modificações de um arquivo específico (alterações, adições ou exclusões) da sua área de trabalho para a staging area (índice) do Git

- git commit faz ? : git commit salva as alterações localmente no seu repositório Git

- git diff faz ? : O git diff é um comando essencial para visualizar as diferenças entre versões de arquivos, commits ou branches no Git

- git push origin [branch] faz ?: git push origin é executado para efetuar push das alterações locais para o repositório online

- git pull faz ? : O comando git pull é utilizado para atualizar o repositório local com as alterações mais recentes de um repositório remoto, sincronizando seu trabalho
